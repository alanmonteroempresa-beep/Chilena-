# chilena ⚽

**Del llano a tu celular.** La red social del fútbol llanero, con gestión de ligas integrada. Versión beta.

## Arrancar
1. Sigue `docs/SETUP.md` (GitHub, Supabase, Vercel, todo gratis).
2. Exporta las pantallas de Claude Design a `docs/diseno/` y el logo a `public/brand/`.
3. Abre Claude Code en la raíz del repo y pega el prompt de la **Fase 0** de `docs/ROADMAP.md`.
4. Después de la Fase 1, cada quien toma su carril: 🟣 Operación o 🔵 Social.
