# Pantallas de diseño de Chilena

Referencia visual para Claude Code. **Si existe una pantalla, se respeta** (CLAUDE.md). El mapa pantalla → ruta → módulo está en `docs/DISENO.md` §6.

## Carpetas
| Carpeta | Qué tiene |
|---|---|
| `pantallas/` | Un PNG por pantalla (cada lámina trae la versión de escritorio y/o celular). **Empieza aquí.** |
| `html/` | El export de Claude Design (`*.dc.html`). Es la mejor referencia para **medidas, colores, textos y espaciados exactos**: lee el HTML de la pantalla que estés implementando. Los celulares se arman con el componente `html/Cel.dc.html`. |
| `referencias/` | Logo y paleta originales. |

## ⚠️ Pantallas 01–24 (deck original, antes del rebrand)
Vienen del deck de **Pelotazo**. Al implementarlas aplica SIEMPRE el rebrand y la navegación final:
- "PELOTAZO" → logo de **chilena**; `pelotazo.mx` → `chilena.mx`.
- Rol "Seguidor/a" → **Aficionado/a**; "Organizador" → **Liga**.
- Sidebar de escritorio: **Inicio · En vivo · Mi liga · Perfil** (sin "Golazos" ni "Fútbol Pro").
- Barra de celular: **Inicio · En vivo · [Publicar / Pase de lista / Capturar] · Mi liga · Perfil**.
- Modo claro: ver `03-05-10-modo-claro-celular.png`, `11-14-modo-claro-celular-barra.png`, `18-panel-de-la-liga-claro.png`, `mi-liga-claro.png` y `sistema-modo-claro-vs-oscuro.png`.

Las pantallas 25 en adelante, Mi Liga y las de modo claro **ya están con el rebrand**.
